Version 1.0.0 Build 85

Build 85 translates subtitles into your language, per profile, and can keep the original line above the translation. Cedar now speaks six more languages: Italian, Japanese, Polish, Russian, Turkish and Spanish for Spain. Posters can show when a film or series is coming back, and Home gets a Right Now Branch for what’s on live. The Sports Bar adds cricket, a list layout and a game window that keeps playing while you read the game page. Apple TV finally gets every app icon, Film Strip included.

Highlights

New

Subtitle translation

Translate subtitles into the language you choose, set for each profile. Show Original Too keeps the original line above the translation.

New

Release labels

Posters can show Release Date, Return Date, Airing, Renewed, Series Cancelled or Binge Ready at a glance.

Add a Home Branch with live games, favourite channels on now and reminders starting soon.

App icons

Every app icon is free for everyone, and all eight, Film Strip included, are on Apple TV and Android TV.

Fixes

8 fixed

  • Home edits, downloads and PIN checks say when something goes wrong instead of failing quietly. Apple devices
  • A PIN check that can’t read the PIN says so instead of reporting a wrong PIN. Android TV
  • Kids profiles hide titles above the Rating Limit from Home rows, Search and Explore. Android TV
  • Downloaded files keep the right file extension. Apple devices
  • Unusual 4K HEVC video no longer restarts Cedar, and Dolby Vision Profile 7 and upscaling no longer freeze on older Apple TVs. Apple TV
  • Search no longer shows results for a query you were still typing. Android TV
  • A saved stream link that stops working recovers instead of failing playback. Android TV
  • Imported DVR settings keep their excluded sources. Android TV
