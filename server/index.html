CEDAR SERVER

Record Live TV without a Mac.

Cedar Server is the Cedar Home DVR as a free Docker container. Run it on a NAS, a mini PC, a Raspberry Pi or a VPS, pair Cedar on iPhone, iPad or Apple TV with it, and schedule recordings that keep happening with every app closed.

How it works

  1. Run the container

    Start Cedar Server with Docker on a computer that stays on, such as a NAS or mini PC.

  2. Pair Cedar

    In Settings › Live TV & DVR › Home DVR, enter the server’s address and the code from its log.

  3. Record

    Cedar sends your Live TV sources and guides. Recordings, series, title and channel rules keep running with every Cedar app closed.

What you need

  • A Linux computer that runs Docker, with an Intel, AMD or ARM processor (64-bit). Synology, Unraid, TrueNAS, a Raspberry Pi 4 or 5 and most mini PCs work.
  • Cedar on iPhone, iPad or Apple TV, build 80 or later. The Mac app can host its own Home DVR but can’t use Cedar Server yet.
  • An M3U, Xtream or Stalker source in Cedar that you are authorized to use. Its TV guide lets series, title and channel rules record on their own.
  • Space for recordings: an hour of HD takes roughly 3–6 GB.

A computer at home works best. Many providers block data-centre addresses or limit how many places can stream at once, so a VPS may not record.

Install with Docker Compose

On a Synology or Unraid server? Follow the Synology or Unraid steps instead, then pair Cedar.

Make a folder for Cedar Server with config and recordings folders inside, and save this as docker-compose.yml next to them:

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

Set TZ to your time zone, and PUID and PGID to the user and group that own the recordings folder (id shows yours). Then start it and watch the log:

docker compose up -d
docker compose logs -f

Next, pair Cedar with the code from the log.

Synology

  1. Install Container Manager from Package Center.
  2. In File Station, create docker/cedar-server with config and recordings folders inside.
  3. In Container Manager, open Project › Create, choose that folder, select Create docker-compose.yml and paste the file above.
  4. Set PUID and PGID to your DSM user’s IDs. The first user is usually 1026 and the users group is 100; id over SSH confirms it.
  5. Finish the wizard, then open the container’s Log tab for the pairing code and pair Cedar.

Unraid

  1. Save cedar-server.xml to /boot/config/plugins/dockerMan/templates-user/ on the flash drive.
  2. On the Docker tab, choose Add Container and pick cedar-server from the Template list.
  3. Check the Config and Recordings paths and choose Apply. The template runs as nobody:users (99:100), like most Unraid containers.
  4. Open the container’s log for the pairing code and pair Cedar.

Pair Cedar

  1. Find the six-digit pairing code in the log. A new one appears at every start, and every 10 minutes until a device pairs.
  2. In Cedar, open Settings › Live TV & DVR › Home DVR.
  3. Enter the server’s address (such as 192.168.1.20), port 8984 and the code, then choose Pair with Home DVR.

Cedar then sends your household’s Live TV sources and guides to the server. Choose which ones it records from under Recordable Sources. To pair another device later, restart the container and use the new code.

Open http://<address>:8984/ in a browser for a status page with the version, storage, sources and paired devices. It never shows the pairing code.

Away from home

Cedar uses the server over your home network. To watch and schedule from elsewhere, give the server an https:// address and set it as CEDAR_REMOTE_URL:

  • Tailscale: run tailscale serve --bg 8984 on the server and use the https://…ts.net name it prints. Devices running Cedar need Tailscale too.
  • Reverse proxy: Caddy, Nginx Proxy Manager or Synology’s reverse proxy with a TLS certificate in front of port 8984.

Cedar only connects to a remote address over HTTPS. Don’t forward port 8984 on your router.

Updates and backups

Update with docker compose pull and then docker compose up -d, or Check for Updates on Unraid. The 1 tag follows every 1.x release; pin a version such as 1.0.0 to update only when you choose.

Back up the config folder. It holds the server’s identity, paired devices, schedules, rules and guide. Recordings are video files in the recordings folder; copy them wherever you like.

Privacy

Cedar Server runs on your computer and talks only to your paired devices and your own providers. Cedar doesn’t receive your recordings, sources or viewing.

The provider addresses and sign-ins that Cedar sends are kept in the config folder, readable only by the server’s user, and are never written to the log. Anyone who can read that folder can read them, so keep it private. The status page shows counts only, never source names, addresses or codes.

Not available yet

  • Jellyfin and Emby Live TV sources. Record those with a Home DVR on a Mac.
  • Finding the server automatically, and pairing without a code through your Apple Account.
  • Cedar for Mac and Android TV as clients of Cedar Server.
