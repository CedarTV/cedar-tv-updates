# Android TV follow-up for Apple 1.0.0 (14)

September 10, 2026. Scope: Android TV, Google TV and Android-based Fire TV. This is an implementation handoff, not an Android release announcement. Android remains at published 1.2.85 (88); this Apple release does not publish an APK or alter the signed OTA manifest.

The current Android source was inspected alongside the Apple implementation reports. Existing profile creation and onboarding fixes are already in Android's Unreleased changelog. Preserve those changes and the prior parity work.

## Already implemented or platform-specific

- Add/Manage Profiles, name/avatar choice, independent resumable onboarding, and vertically centered onboarding actions are implemented in Android's current working tree; they are not yet published in a new Android build.
- Android already has remote next/previous/most-recent channel actions. Preserve them and test their channel context and cancellation; do not transplant iPhone edge swipes or touch brightness/volume controls onto a TV remote.
- Apple CloudKit share migration, push entitlements, legacy Keychain handling and Mac native accessibility are Apple responsibilities. Android retains independent one-time profile copies and its current Android Keystore path.
- The shorter iOS tab-bar Watching Now accessory is platform-specific. Adapt only if Android has an equivalent oversized surface.
- TMDB hero scores were already enabled by default in Cedar's Apple presentation. This was an investigation, not a newly added rating provider. Do not describe it as a new Android gap without checking the active hero settings/data.

## Acceptance before an Android release

Use delayed/failing subtitle fixtures, an extensionless SRT response, alternate language/release files, malformed responses and media/profile switches. Verify first-frame independence, actual decoded cues, Off, seeking, offset persistence/isolation and no stale selected state. Exercise the real guide/source/player path with multiple playlists and D-pad navigation. Check different media cuts conservatively. Run Android unit/UI/lint/release-signing checks and then qualify representative physical Android TV/Google TV/Fire TV devices. Do not promote the existing parity contract to fully verified based on a build alone.

Apple evidence: the September 10 subtitle, collection, source-selector, guide, compact-rating and timed-action reports; September 9 profile/onboarding and Apple TV changelog-reader reports. Prior Android evidence: `docs/APPLE_PARITY_REVIEW_2026-09-09.md`.
