Получить Cedar

CEDAR SERVER

Запись прямого эфира без Mac.

Cedar Server — это Домашний DVR Cedar в виде бесплатного контейнера Docker. Запустите его на NAS, мини-ПК, Raspberry Pi или VPS, сопрягите с ним Cedar на iPhone, iPad или Apple TV и планируйте записи, которые продолжаются при закрытых приложениях.

Как это работает

  1. Запустите контейнер

    Запустите Cedar Server в Docker на компьютере, который остаётся включённым, например на NAS или мини-ПК.

  2. Сопрягите Cedar

    В разделе «Настройки» › «Прямой эфир и DVR» › «Домашний DVR» введите адрес сервера и код из его журнала.

  3. Запись

    Cedar отправляет ваши источники прямого эфира и программы передач. Записи, сериалы, правила для названий и каналов продолжают работать при закрытых приложениях Cedar.

Что понадобится

  • Компьютер с Linux, на котором работает Docker, с 64-битным процессором Intel, AMD или ARM. Подойдут Synology, Unraid, TrueNAS, Raspberry Pi 4 или 5 и большинство мини-ПК.
  • Cedar на iPhone, iPad или Apple TV, сборка 80 или новее. Приложение для Mac может запускать собственный Домашний DVR, но пока не может использовать Cedar Server.
  • Источник M3U, Xtream или Stalker в Cedar, которым вам разрешено пользоваться. Его программа передач позволяет правилам для сериалов, названий и каналов записывать самостоятельно.
  • Место для записей: час в HD занимает примерно 3–6 ГБ.

Лучше всего подходит домашний компьютер. Многие провайдеры блокируют адреса дата-центров или ограничивают число мест, с которых можно смотреть одновременно, поэтому на VPS запись может не работать.

Установка через Docker Compose

Используете Synology или Unraid? Вместо этого выполните шаги для Synology или Unraid, а затем сопрягите Cedar.

Создайте папку для Cedar Server, а в ней папки config и recordings, и сохраните рядом с ними этот файл как docker-compose.yml:

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

Укажите в TZ свой часовой пояс, а в PUID и PGID — пользователя и группу, которым принадлежит папка с записями (их показывает команда id). Затем запустите сервер и следите за журналом:

docker compose up -d
docker compose logs -f

Теперь сопрягите Cedar с помощью кода из журнала.

Synology

  1. Установите Container Manager из Центра пакетов.
  2. В File Station создайте папку docker/cedar-server, а в ней папки config и recordings.
  3. В Container Manager откройте «Проект» › «Создать», выберите эту папку, выберите «Создать docker-compose.yml» и вставьте файл, приведённый выше.
  4. Укажите в PUID и PGID идентификаторы вашего пользователя DSM. Обычно у первого пользователя это 1026, а у группы users — 100; проверить можно командой id по SSH.
  5. Завершите работу мастера, затем откройте вкладку «Журнал» контейнера, чтобы найти код сопряжения, и сопрягите Cedar.

Unraid

  1. Сохраните cedar-server.xml в /boot/config/plugins/dockerMan/templates-user/ на флеш-накопителе.
  2. На вкладке Docker выберите «Add Container» и выберите cedar-server в списке шаблонов.
  3. Проверьте пути Config и Recordings и нажмите «Apply». Шаблон запускается от nobody:users (99:100), как и большинство контейнеров Unraid.
  4. Откройте журнал контейнера, чтобы найти код сопряжения, и сопрягите Cedar.

Сопрягите Cedar

  1. Найдите в журнале шестизначный код сопряжения. Новый код появляется при каждом запуске и каждые 10 минут, пока не будет сопряжено устройство.
  2. В Cedar откройте «Настройки» › «Прямой эфир и DVR» › «Домашний DVR».
  3. Введите адрес сервера (например, 192.168.1.20), порт 8984 и код, затем выберите «Связать с домашним DVR».

После этого Cedar отправляет на сервер источники прямого эфира и программы передач вашего домохозяйства. Выберите, какие из них записывать, в разделе «Источники с возможностью записи». Чтобы позже сопрячь другое устройство, перезапустите контейнер и используйте новый код.

Откройте в браузере http://<address>:8984/, чтобы увидеть страницу состояния с версией, хранилищем, источниками и сопряжёнными устройствами. Код сопряжения она никогда не показывает.

Вне дома

Cedar использует сервер в вашей домашней сети. Чтобы смотреть и планировать записи из другого места, задайте серверу адрес https:// и укажите его в CEDAR_REMOTE_URL:

  • Tailscale: выполните на сервере tailscale serve --bg 8984 и используйте имя https://…ts.net, которое оно выведет. Устройствам с Cedar тоже нужен Tailscale.
  • Обратный прокси: Caddy, Nginx Proxy Manager или обратный прокси Synology с сертификатом TLS перед портом 8984.

Cedar подключается к удалённому адресу только по HTTPS. Не пробрасывайте порт 8984 на роутере.

Обновления и резервные копии

Обновляйте командами docker compose pull и docker compose up -d или через «Check for Updates» в Unraid. Тег 1 следует за каждым выпуском 1.x; закрепите версию, например 1.0.0, чтобы обновляться только по своему выбору.

Делайте резервную копию папки config. В ней хранятся идентификатор сервера, сопряжённые устройства, расписания, правила и программа передач. Записи — это видеофайлы в папке recordings; копируйте их куда угодно.

Конфиденциальность

Cedar Server работает на вашем компьютере и общается только с вашими сопряжёнными устройствами и вашими провайдерами. Cedar не получает ваши записи, источники и историю просмотров.

Адреса провайдеров и данные для входа, которые отправляет Cedar, хранятся в папке config, доступны для чтения только пользователю сервера и никогда не записываются в журнал. Любой, кто может прочитать эту папку, может прочитать и их, поэтому держите её закрытой. Страница состояния показывает только количество, но никогда не названия источников, адреса или коды.

Пока недоступно

  • Источники прямого эфира Jellyfin и Emby. Записывайте их с помощью Домашнего DVR на Mac.
  • Автоматический поиск сервера и сопряжение без кода через ваш Apple Account.
  • Cedar для Mac и Android TV как клиенты Cedar Server.
