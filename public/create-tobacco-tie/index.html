What is a Tobacco Tie? +

A Tobacco Tie encrypts an add-on address into a portable code. The code includes its key: anyone with the complete tie can recover the address and install it. Keep ties private when they contain account access.

Cedar creates the code locally without connecting to the add-on. Creating a tie does not check that the add-on works or is compatible with Cedar. Only use sources you are authorized to access.
