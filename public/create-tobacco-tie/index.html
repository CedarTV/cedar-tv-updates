What is a Tobacco Tie? +

A Tobacco Tie turns your Cedar Library URL into a portable username and password. These are generated import values, so you do not need a Cedar account. Anyone with both can install the tie. Keep them private when they contain account access.

Cedar creates both values locally without connecting to your Cedar Library. In the app, the server URL is used for a connection check; your username and password stay on your device while Cedar decodes the tie. Creating a tie does not check that your Cedar Library URL works or is compatible with Cedar. Only use sources you are authorized to access.
