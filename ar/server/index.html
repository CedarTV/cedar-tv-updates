CEDAR SERVER

سجّل البث التلفزيوني المباشر دون Mac.

Cedar Server هو DVR المنزل في Cedar كحاوية Docker مجانية. شغّله على NAS أو حاسوب مصغّر أو Raspberry Pi أو VPS، واقرنه مع Cedar على iPhone أو iPad أو Apple TV، وجدوِل تسجيلات تستمر مع إغلاق كل التطبيقات.

كيف يعمل

  1. شغّل الحاوية

    شغّل Cedar Server بواسطة Docker على حاسوب يبقى قيد التشغيل، مثل NAS أو حاسوب مصغّر.

  2. اقرن Cedar

    في الإعدادات › البث المباشر وDVR › DVR المنزل، أدخل عنوان الخادم والرمز من سجلّه.

  3. سجّل

    يرسل Cedar مصادر البث التلفزيوني المباشر وأدلتك. تستمر التسجيلات والمسلسلات وقواعد العناوين والقنوات في العمل مع إغلاق كل تطبيقات Cedar.

ما تحتاج إليه Docker Compose Synology Unraid اقرن Cedar بعيدًا عن المنزل الإعدادات التحديثات والنسخ الاحتياطية الخصوصية غير متوفر بعد

ما تحتاج إليه

  • حاسوب Linux يشغّل Docker، بمعالج Intel أو AMD أو ARM (64 بت). تعمل أجهزة Synology وUnraid وTrueNAS وRaspberry Pi 4 أو 5 ومعظم الحواسيب المصغّرة.
  • Cedar على iPhone أو iPad أو Apple TV، البناء 80 أو أحدث. يمكن لتطبيق Mac استضافة DVR المنزل الخاص به لكنه لا يستطيع استخدام Cedar Server بعد.
  • مصدر M3U أو Xtream أو Stalker في Cedar مصرّح لك باستخدامه. يتيح دليله التلفزيوني لقواعد المسلسلات والعناوين والقنوات التسجيل تلقائيًا.
  • مساحة للتسجيلات: ساعة بجودة HD تشغل نحو 3–6 GB.

الحاسوب المنزلي هو الأفضل. يحظر كثير من المزوّدين عناوين مراكز البيانات أو يحدّون عدد الأماكن التي تبث في آن واحد، لذا قد لا يسجّل VPS.

التثبيت باستخدام Docker Compose

هل لديك خادم Synology أو Unraid؟ اتبع خطوات Synology أو Unraid بدلًا من ذلك، ثم اقرن Cedar.

أنشئ مجلدًا لـ Cedar Server يضم بداخله مجلدي config وrecordings، واحفظ هذا باسم docker-compose.yml بجوارهما:

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

اضبط TZ على منطقتك الزمنية، وPUID وPGID على المستخدم والمجموعة اللذين يملكان مجلد التسجيلات (يعرض id قيمهما). ثم شغّله وراقب السجل:

docker compose up -d
docker compose logs -f

بعد ذلك، اقرن Cedar بالرمز من السجل.

Synology

  1. ثبّت Container Manager من Package Center.
  2. في File Station، أنشئ docker/cedar-server وبداخله مجلدا config وrecordings.
  3. في Container Manager، افتح Project › Create، واختر ذلك المجلد، وحدّد Create docker-compose.yml والصق الملف أعلاه.
  4. اضبط PUID وPGID على معرّفات مستخدم DSM لديك. المستخدم الأول عادةً 1026 ومجموعة users هي 100؛ ويؤكد id عبر SSH ذلك.
  5. أكمل المعالج، ثم افتح تبويب Log في الحاوية للحصول على رمز الاقتران، ثم اقرن Cedar.

Unraid

  1. احفظ cedar-server.xml في /boot/config/plugins/dockerMan/templates-user/ على قرص الفلاش.
  2. في تبويب Docker، اختر Add Container وحدّد cedar-server من قائمة Template.
  3. تحقق من مساري Config وRecordings واختر Apply. يعمل القالب بصفة nobody:users (99:100)، مثل معظم حاويات Unraid.
  4. افتح سجل الحاوية للحصول على رمز الاقتران، ثم اقرن Cedar.

اقرن Cedar

  1. ابحث عن رمز الاقتران المكوّن من ستة أرقام في السجل. يظهر رمز جديد عند كل تشغيل، وكل 10 دقائق إلى أن يقترن جهاز.
  2. في Cedar، افتح الإعدادات › البث المباشر وDVR › DVR المنزل.
  3. أدخل عنوان الخادم (مثل 192.168.1.20) والمنفذ 8984 والرمز، ثم اختر اقتران مع DVR المنزل.

يرسل Cedar بعد ذلك مصادر البث التلفزيوني المباشر وأدلة أسرتك إلى الخادم. اختر ما يسجّله منها من ضمن المصادر القابلة للتسجيل. لإقران جهاز آخر لاحقًا، أعد تشغيل الحاوية واستخدم الرمز الجديد.

افتح http://<address>:8984/ في متصفح لتظهر صفحة حالة بالإصدار والتخزين والمصادر والأجهزة المقترنة. لا تعرض رمز الاقتران أبدًا.

بعيدًا عن المنزل

يستخدم Cedar الخادم عبر شبكتك المنزلية. للمشاهدة والجدولة من مكان آخر، امنح الخادم عنوان https:// واضبطه في CEDAR_REMOTE_URL:

  • Tailscale: شغّل tailscale serve --bg 8984 على الخادم واستخدم الاسم https://…ts.net الذي يطبعه. تحتاج الأجهزة التي تشغّل Cedar إلى Tailscale أيضًا.
  • الوكيل العكسي: Caddy أو Nginx Proxy Manager أو الوكيل العكسي في Synology مع شهادة TLS أمام المنفذ 8984.

لا يتصل Cedar بعنوان بعيد إلا عبر HTTPS. لا تعيد توجيه المنفذ 8984 على جهاز التوجيه.

التحديثات والنسخ الاحتياطية

حدّث بالأمر docker compose pull ثم docker compose up -d، أو Check for Updates على Unraid. الوسم 1 يتبع كل إصدار 1.x؛ ثبّت إصدارًا مثل 1.0.0 لتحدّث فقط عندما تختار.

احتفظ بنسخة احتياطية من مجلد config. فهو يحتوي هوية الخادم والأجهزة المقترنة والجداول والقواعد والدليل. التسجيلات ملفات فيديو في مجلد التسجيلات؛ انسخها إلى أي مكان تشاء.

الخصوصية

يعمل Cedar Server على حاسوبك ولا يتحدث إلا مع أجهزتك المقترنة ومزوّديك الخاصين. لا يتلقى Cedar تسجيلاتك ولا مصادرك ولا مشاهداتك.

عناوين المزوّدين وبيانات تسجيل الدخول التي يرسلها Cedar تُحفَظ في مجلد config، ولا يقرؤها إلا مستخدم الخادم، ولا تُكتب أبدًا في السجل. يمكن لأي شخص يستطيع قراءة ذلك المجلد قراءتها، لذا أبقِه خاصًا. تعرض صفحة الحالة الأعداد فقط، ولا تعرض أبدًا أسماء المصادر أو العناوين أو الرموز.

غير متوفر بعد

  • مصادر البث التلفزيوني المباشر من Jellyfin وEmby. سجّلها بواسطة DVR المنزل على Mac.
  • العثور على الخادم تلقائيًا، والاقتران دون رمز عبر حساب Apple.
  • Cedar لأجهزة Mac وAndroid TV كعملاء لـ Cedar Server.
