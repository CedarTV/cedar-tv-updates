プライバシーポリシー

Cedar はローカルファーストです。Cedar では、開発者が運営するユーザーアカウントは不要で、広告ネットワーク、分析バックエンド、メディアサービスも運営していません。任意の同期機能と接続サービス機能については、以下で説明します。

お使いのデバイス上のデータ

プロファイル、ライブラリの記録、視聴の進捗、ソースの設定、ダウンロード、環境設定は、ローカルに保存されます。プロバイダーのパスワード、アクセストークン、API キーは、通常の環境設定ではなく、システムのキーチェーンに保存されます。ソースや接続したアカウントを削除すると、Cedar が保存している認証情報への参照も削除されます。Cedar を削除すると、アプリコンテナのデータは削除されます。キーチェーンに残るかどうかは、オペレーティングシステムの動作にも左右されます。

Apple との同期（任意）

iCloud 同期を有効にすると、Cedar は、デバイス間の一貫性を保つために必要なプロファイル、ライブラリ、再生状態、環境設定を、プライベートな CloudKit コンテナに保存します。Cedar 世帯では、持ち運び可能なプロバイダーの認証情報を、デバイス上で暗号化してから、プライベートな CloudKit 共有に置きます。招待された世帯メンバーは、Apple の招待を承諾したあと、対応する持ち運び可能な値を使用できます。デバイス管理用のシークレットはローカルに残ります。

接続するサービス

Cedar が接続するのは、お客様が選んだ機能に必要なサービスだけです。設定済みのメディアソース、メタデータとアートワークのプロバイダー、任意のトラッキングやウォッチリストのアカウント、字幕やアドオンのエンドポイント、公開されているスポーツデータのプロバイダーなどです。リクエストはお使いのデバイスからそれらのサービスへ直接送られ、各サービスのプライバシーポリシーに従って扱われます。

Trakt、Simkl、MDBList を接続した場合、Cedar は、有効にした同期の操作に必要な、接続したアカウントの識別子と、タイトルの識別子、進捗、タイムスタンプ、履歴、ウォッチリストの変更、評価を、そのサービスに送信します。

Discord を連携し、iPhone、iPad、Mac で「視聴中の内容を共有」をオンにすると、Cedar の再生中、お使いのデバイスは、プロファイルが許可する状況(タイトル、エピソード、公開されているポスター画像、経過時間、または Cedar で何かを視聴中であることだけ)を Discord に送信します。この情報は、Discord の SDK を通じて、お使いのデバイスから Discord へ直接送られ、再生が止まると消去され、キッズプロファイルでは利用できません。Discord のサインイン情報はキーチェーンに保存され、iCloud キーチェーンを通じて他の Apple デバイスと同期されます。Cedar 世帯に追加されることはありません。Discord のプライバシーポリシーをご確認ください。

さらに「評価を共有」をオンにすると、評価のシートに、Cedar の Discord サーバーの #ratings チャンネルへ評価を投稿するオプションが表示されます。共有したときにのみ、お使いのデバイスは、タイトルの TMDB または IMDb の識別子、シーズンとエピソードの番号、スコア、Discord のサインイン情報を、Cedar のフィードバックサービスに送信します。このサービスは、サインイン情報を、Discord アカウントの照会とサーバーへの参加の確認のために一度だけ使用し、保存しません。TMDB からタイトル、年、ポスターを取得し、スコアとともに、お客様の Discord アカウントへのメンションつきで投稿します。投稿はサーバーの全員が見られます。同じタイトルを再度評価したときに同じ投稿が更新されるよう、Discord のユーザー ID、タイトル、スコア、投稿の ID を最長1年間保持します。Cedar で評価を削除すると、投稿とその記録が削除されます。「評価を共有」はデフォルトでオフで、キッズプロファイルでは利用できません。

Cedar Link（提供終了）

Cedar Link は、Apple のプロファイルを他の Cedar デバイスやブラウザとつなぐ、任意の暗号化リレーでしたが、終了しました。更新された Cedar アプリは、デバイスに残っている Cedar Link のサインイン情報を削除します。リレーが停止するまでの間は、すでに保持している暗号化された記録と限られたルーティング用メタデータだけを保持し、これらの内容を読み取ることはできません。

YouTube の予告編

これらの同意のコントロールは App Store でのリリースに向けて準備中で、以前の TestFlight ビルドにはまだ含まれていない場合があります。

iPhone、iPad、Mac では、選択した予告編に YouTube の埋め込みプレーヤーを使用します。Google は、再生、パーソナライズ、分析、広告のために、識別子、IP アドレスから推定される大まかな位置情報、視聴と広告に関する操作、技術的な利用データを受け取ります。App Store でのリリース版の実装では、セッションごとに読み込む前に確認し、一時的なウェブストレージを使用し、自動再生を無効にします。iPhone と iPad では Apple のトラッキング許可も必要で、拒否した場合は、ユーザーが YouTube を外部で開けます。埋め込みの YouTube は、キッズプロファイルでは利用できません。プレーヤーを閉じるとローカルのセッションは終了しますが、Google がすでに保持している情報は削除されません。Apple TV では YouTube を外部で開きます。プレーヤーの利用には、YouTube の利用規約 https://www.youtube.com/t/terms と、Google のプライバシーポリシー https://policies.google.com/privacy が適用されます。

AI 検索（任意）

AI 検索では、お客様ご自身の Gemini API キーを使用します。Google は、キー、ネットワーク情報、送信した説明文を受け取ります。Cedar がメディアソースの認証情報や視聴履歴を付け加えることはありません。Google は現在、不正利用の監視のため、プロンプトと応答を55日間保持しています。無料のリクエストは、人によるレビューの対象となったり、製品やモデルの改善に利用されたりする場合があります。有料サービスのデータに関する規約は異なります。機密情報は入力しないでください。App Store でのリリース版の実装では、検証や検索の前に、プロファイルごとのデバイス内のプライバシーに関する選択、成人であることの確認、Google の地域要件と課金要件の確認が必要です。キッズプロファイルでは AI 検索を利用できません。今後のリクエストを止めるには、Gemini の設定でデータ共有をオフにして保存するか、接続を削除してください。これらの確認では、年齢、所在地、課金状況は検証されません。Gemini の利用規約: https://ai.google.dev/gemini-api/terms ; データ保持: https://ai.google.dev/gemini-api/docs/usage-policies ; 対応地域: https://ai.google.dev/gemini-api/docs/available-regions

お支払い

予定されている App Store でのリリースは、外観のオプションも含めてすべて無料で、購入できるものはありません。以前の TestFlight プレビューでは、未完成のサポーター向け購入画面が表示されることがあります。Cedar は、支払いカードや銀行口座の情報を収集しません。別途ご契約のサービスには、それぞれの規約が引き続き適用されます。

フィードバックと不具合の報告

Cedar のウェブサイトまたはアプリから不具合の報告や機能のリクエストを送信すると、Cedar のボットが、お客様のお名前なしで、Cedar の Discord の不具合フォーラムまたは機能リクエストフォーラムに公開で投稿します。投稿されるのは、概要と説明、選択したアプリまたはデバイス、含めた場合は Cedar のバージョンです。アプリのシステムバージョン、デバイスのモデル、スタッフ専用の欄に書いた内容は投稿されず、Cloudflare 上の Cedar のフィードバックサービスにある非公開のレポートにのみ保管されます。レポートは Cedar の開発者が読み、販売したり広告に使用したりすることはありません。古いバージョンのアプリからのレポートは、自動では投稿されません。

アプリの「フィードバックを送信」で診断情報を添付した場合、アプリが伏せ字処理した診断のエクスポートが、Cedar チームだけが見られる Cedar の Discord の非公開スタッフチャンネルにファイルとしてアップロードされ、非公開のレポートからそのファイルにリンクされます。スタッフが削除するまで、そこに保管されます。

Cedar の Discord のレポートフォームでは、タイトル、デバイス、Cedar のバージョン、説明が、お客様の Discord 名で、サーバーの不具合フォーラムまたは機能リクエストフォーラムに公開で投稿され、同じレポートが Cedar のフィードバックサービスにも送信されます。スタッフ専用の欄に書いた内容は投稿されず、非公開のレポートにのみ保管されます。このフォームの1日あたりの上限は、毎日変わる、Discord のユーザー ID のソルトつき一方向ハッシュを使って数えられます。Cedar の Discord で報告した場合、Cedar のボットは、スタッフがレポートを担当したとき、およびステータスが変わったときに、ダイレクトメッセージを送ります。「この通知を停止」を選ぶと、再び通知しないように Cedar が Discord のユーザー ID を保持します。「通知を再開」を選ぶと、それが削除されます。

ウェブサイトと現在のバージョンのアプリは、メールアドレスを求めません。古いバージョンのアプリがメールアドレスを送信していた場合、それが投稿されることはなく、非公開のレポートにのみ保管され、レポートの確認が済み次第、削除されます。確認済みで非公開の作業チケットに紐づけられていないレポートは、30日後に削除されます。紐づけられているレポートは、そのチケットが存在する間、Cedar の開発者のために非公開で保管され、チケットの削除から30日以内に削除されます。レポートに Cedar の Discord の投稿がある場合、その投稿への以降の返信は、同じ非公開チケットにコピーされます。未確認のレポートは、1年後に削除されます。1日あたりの不正利用カウンターには、毎日変わる、お客様のネットワークアドレスのソルトつき一方向ハッシュを使用し、アドレス自体は保存しません。Cedar の開発者がレポートについて Cedar の Discord に公開の投稿を作成する場合、その投稿は、お客様のレポート、お名前、メールアドレスを使わず、新たに書き起こされます。

診断情報

Cedar は、ネイティブアプリの診断情報を、Cedar のサーバーに自動でアップロードすることはありません。任意のローカルレポートは、お客様がエクスポートして共有したとき、またはアプリの「フィードバックを送信」に添付したとき(Cedar のスタッフにのみ送信されます)にだけ、デバイスの外に出ます。Google のサービスは、運用、セキュリティ、分析のために、リクエストに関連するパフォーマンス情報と技術的な診断情報を保持することがあります。Apple の診断は、お客様の Apple の設定とポリシーに従います。

トラッキングと広告

Cedar は広告ネットワークを運営せず、個人情報を販売しません。埋め込みの YouTube サービスは、広告と測定のために、アプリやウェブサイトをまたいで、識別子、大まかな位置情報、動画や広告に関する操作を使用することがあります。そのため Cedar は、第三者によるトラッキングを開示しています。App Store でのリリース版は、セッションへの同意があった場合にのみ、iPhone と iPad では Apple のトラッキング許可があった場合にのみ、プレーヤーを読み込みます。Gemini の検索テキストは、機能、分析、および無料のモデル開発などのその他の目的のために開示されるものであり、広告データとしてではありません。

アクセス許可

対応する iPhone と iPad では、カメラへのアクセスは、一度限りの Cedar デバイス連携 QR コードをスキャンすることを選んだときにのみ要求されます。コードの手入力も可能です。Cedar は写真や動画を撮影したりアップロードしたりしません。ローカルネットワークへのアクセスは、お客様が設定した Cedar デバイス、リモコン、DVR、メディアサーバーを検出して接続するために使用します。Apple TV では、シネマ照明が、選んだ部屋の照明を暗くして元に戻すために「ホーム」へのアクセスを求め、日没スケジュールを選んだ場合にのみ、Apple TV のおおよその位置を一度調べるために位置情報へのアクセスを求めます。位置情報と HomeKit の選択内容はその Apple TV 内にとどまり、Cedar に送信されることはありません。

ネットワークセキュリティ

Cedar は HTTPS を優先します。ユーザーが運用するメディアサーバーの中には HTTP にしか対応していないものがあるため、平文の接続では認証情報、番組表データ、視聴状況が漏れるおそれがあるという警告を表示した場合にのみ、Cedar はお客様が指定したアドレスに接続できます。Cedar は、HTTPS から HTTP へのリダイレクトを拒否します。

お子様とコンテンツ

Cedar は、13歳未満のお子様を対象としていません。Cedar に表示されるメディアは、ユーザーが設定したソースによって決まります。Cedar は、映画、番組、チャンネル、プレイリスト、アドオン、メディアプロバイダーのサブスクリプション、プロバイダーの認証情報を提供しません。

選択肢とお問い合わせ

サービスの接続解除、ソースとプロファイルの削除、任意の同期機能の無効化、リンクしたデバイスの取り消し、ローカルデータの書き出しや削除、アプリの削除ができます。Cedar はユーザーアカウントのデータベースを運営していないため、書き出しや削除の対象となる Cedar アカウントはありません。Cedar の Discord に共有した評価を取り下げるには、Cedar で評価を削除するか、サポートページからご依頼ください。プライバシーに関するご質問と連絡先は、公開のサポートページをご利用ください。
