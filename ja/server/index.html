Cedar を入手

CEDAR SERVER

Mac なしでライブTVを録画。

Cedar Server は、Cedar ホーム DVR を無料の Docker コンテナにしたものです。NAS、ミニ PC、Raspberry Pi、VPS で動かし、iPhone、iPad、Apple TV の Cedar とペアリングすれば、すべてのアプリを閉じていても続く録画予約ができます。

しくみ

  1. コンテナを実行

    常時起動しておけるコンピュータ(NAS やミニ PC など)で、Docker を使って Cedar Server を起動します。

  2. Cedar とペアリング

    「設定」›「ライブTV & DVR」›「ホームDVR」で、サーバーのアドレスと、ログに表示されるコードを入力します。

  3. 録画

    Cedar がライブTVのソースと番組表を送ります。録画、シリーズ、タイトル、チャンネルのルールは、Cedar アプリをすべて閉じていても動き続けます。

必要なもの

  • Docker が動く Linux コンピュータ(Intel、AMD、ARM の 64 ビットプロセッサ)。Synology、Unraid、TrueNAS、Raspberry Pi 4 または 5、ほとんどのミニ PC で動作します。
  • iPhone、iPad、Apple TV の Cedar(ビルド 80 以降)。Mac アプリは自分のホーム DVR をホストできますが、Cedar Server はまだ使えません。
  • ご利用が許可されている、Cedar 内の M3U、Xtream、Stalker のソース。その番組表があれば、シリーズ、タイトル、チャンネルのルールが自動で録画されます。
  • 録画用の空き容量: HD 1時間でおよそ 3~6 GB が目安です。

自宅にあるコンピュータがおすすめです。多くのプロバイダーは、データセンターのアドレスをブロックしたり、同時にストリーミングできる場所の数を制限したりしているため、VPS では録画できない場合があります。

Docker Compose でインストール

Synology や Unraid サーバーをお使いですか?その場合は、Synology または Unraid の手順に従い、そのあと Cedar とペアリングしてください。

Cedar Server 用のフォルダを作り、その中に config フォルダと recordings フォルダを作成して、次の内容を横に docker-compose.yml として保存します。

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

TZ にはお使いのタイムゾーンを、PUID と PGID には recordings フォルダを所有するユーザーとグループを設定します(id コマンドで確認できます)。そのあと起動して、ログを確認します。

docker compose up -d
docker compose logs -f

次に、ログに表示されたコードで Cedar とペアリングします。

Synology

  1. パッケージセンターから Container Manager をインストールします。
  2. File Station で docker/cedar-server を作成し、その中に config フォルダと recordings フォルダを作ります。
  3. Container Manager で「プロジェクト」›「作成」を開き、そのフォルダを選んで「docker-compose.yml を作成」を選択し、上のファイルを貼り付けます。
  4. PUID と PGID には、DSM ユーザーの ID を設定します。最初のユーザーは通常 1026、users グループは 100 です。SSH で id を実行すると確認できます。
  5. ウィザードを完了したら、コンテナの「ログ」タブでペアリングコードを確認し、Cedar とペアリングします。

Unraid

  1. cedar-server.xml を、フラッシュドライブの /boot/config/plugins/dockerMan/templates-user/ に保存します。
  2. Docker タブで「Add Container」を選び、Template の一覧から cedar-server を選択します。
  3. Config と Recordings のパスを確認して、「Apply」を選びます。このテンプレートは、ほとんどの Unraid コンテナと同じく nobody:users(99:100)で動作します。
  4. コンテナのログでペアリングコードを確認し、Cedar とペアリングします。

Cedar とペアリング

  1. ログに6桁のペアリングコードが表示されます。コードは起動のたびに新しく表示され、デバイスがペアリングされるまで10分ごとに更新されます。
  2. Cedar で「設定」›「ライブTV & DVR」›「ホームDVR」を開きます。
  3. サーバーのアドレス(192.168.1.20 など)、ポート 8984、コードを入力して、「ホームDVRとペアリング」を選びます。

ペアリングが済むと、Cedar は世帯のライブTVソースと番組表をサーバーに送ります。録画の対象は「録画可能なソース」で選べます。あとから別のデバイスをペアリングするには、コンテナを再起動して新しいコードを使います。

ブラウザで http://<address>:8984/ を開くと、バージョン、ストレージ、ソース、ペアリング済みデバイスを表示するステータスページが見られます。ペアリングコードは表示されません。

外出先から

Cedar は、ホームネットワーク経由でサーバーを使います。外出先から視聴や予約をするには、サーバーに https:// のアドレスを用意し、CEDAR_REMOTE_URL に設定します。

  • Tailscale: サーバーで tailscale serve --bg 8984 を実行し、表示される https://…ts.net の名前を使います。Cedar を動かすデバイスにも Tailscale が必要です。
  • リバースプロキシ: Caddy、Nginx Proxy Manager、または Synology のリバースプロキシで、ポート 8984 の前に TLS 証明書を置きます。

Cedar は、リモートのアドレスには HTTPS でしか接続しません。ルーターでポート 8984 を転送しないでください。

設定

設定デフォルト内容
TZUTCお使いのタイムゾーン。毎週のルールが現地の時刻で始まります。
PUID、PGID1000サーバーを実行するユーザーとグループ。recordings フォルダに書き込める必要があります。
CEDAR_SERVER_NAMECedar ServerCedar に表示される名前。
CEDAR_MAX_RECORDINGS2同時に録画できる数(1~8)。プロバイダーの接続数の上限内に収めてください。
CEDAR_REMOTE_URLなし外出先で使うための https:// アドレス。
CEDAR_PORT8984コンテナ内のポート。

アップデートとバックアップ

docker compose pull に続けて docker compose up -d を実行して更新します。Unraid では「Check for Updates」を使います。1 タグは 1.x のすべてのリリースに追従します。1.0.0 のようにバージョンを固定すると、好きなときにだけ更新できます。

config フォルダをバックアップしてください。サーバーの識別情報、ペアリング済みデバイス、予約、ルール、番組表が入っています。録画は recordings フォルダ内のビデオファイルなので、好きな場所にコピーできます。

プライバシー

Cedar Server はお使いのコンピュータで動作し、ペアリング済みのデバイスとご自身のプロバイダーとしか通信しません。Cedar が録画、ソース、視聴内容を受け取ることはありません。

Cedar が送るプロバイダーのアドレスとサインイン情報は config フォルダに保存され、サーバーのユーザーだけが読み取れます。ログには書き込まれません。このフォルダを読める人は誰でもそれらを読めるため、非公開にしてください。ステータスページに表示されるのは件数だけで、ソース名、アドレス、コードは表示されません。

まだ利用できません

  • Jellyfin と Emby のライブTVソース。これらは Mac のホームDVRで録画してください。
  • サーバーの自動検出と、Apple アカウントを使ったコードなしのペアリング。
  • Mac と Android TV の Cedar を Cedar Server のクライアントとして使うこと。
