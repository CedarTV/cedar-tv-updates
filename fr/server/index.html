CEDAR SERVER

Enregistrez la TV en direct sans Mac.

Cedar Server est le DVR domestique de Cedar sous forme de conteneur Docker gratuit. Lancez-le sur un NAS, un mini-PC, un Raspberry Pi ou un VPS, jumelez-y Cedar sur iPhone, iPad ou Apple TV, et programmez des enregistrements qui continuent même quand toutes les apps sont fermées.

Comment ça marche

  1. Lancez le conteneur

    Démarrez Cedar Server avec Docker sur un ordinateur qui reste allumé, comme un NAS ou un mini-PC.

  2. Jumelez Cedar

    Dans Réglages › TV en direct et DVR › DVR domestique, saisissez l’adresse du serveur et le code affiché dans son journal.

  3. Enregistrez

    Cedar envoie vos sources de TV en direct et vos guides. Les enregistrements, séries et règles par titre ou par chaîne continuent de s’exécuter même quand toutes les apps Cedar sont fermées.

Ce qu’il vous faut

  • Un ordinateur Linux qui exécute Docker, avec un processeur Intel, AMD ou ARM (64 bits). Synology, Unraid, TrueNAS, un Raspberry Pi 4 ou 5 et la plupart des mini-PC conviennent.
  • Cedar sur iPhone, iPad ou Apple TV, build 80 ou ultérieur. L’app Mac peut héberger son propre DVR domestique mais ne peut pas encore utiliser Cedar Server.
  • Une source M3U, Xtream ou Stalker dans Cedar que vous êtes autorisé à utiliser. Son guide TV permet aux règles de séries, de titres et de chaînes d’enregistrer toutes seules.
  • De l’espace pour les enregistrements : une heure en HD occupe environ 3 à 6 Go.

Un ordinateur à la maison fonctionne le mieux. De nombreux fournisseurs bloquent les adresses de centres de données ou limitent le nombre de lieux pouvant diffuser en même temps ; un VPS risque donc de ne pas enregistrer.

Installer avec Docker Compose

Sur un serveur Synology ou Unraid ? Suivez plutôt les étapes Synology ou Unraid, puis jumelez Cedar.

Créez un dossier pour Cedar Server contenant les dossiers config et recordings, et enregistrez ceci sous docker-compose.yml à côté d’eux :

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

Réglez TZ sur votre fuseau horaire, et PUID et PGID sur l’utilisateur et le groupe propriétaires du dossier des enregistrements (id affiche les vôtres). Puis démarrez-le et surveillez le journal :

docker compose up -d
docker compose logs -f

Ensuite, jumelez Cedar avec le code du journal.

Synology

  1. Installez Container Manager depuis le Centre de paquets.
  2. Dans File Station, créez docker/cedar-server avec les dossiers config et recordings à l’intérieur.
  3. Dans Container Manager, ouvrez Projet › Créer, choisissez ce dossier, sélectionnez Créer docker-compose.yml et collez le fichier ci-dessus.
  4. Réglez PUID et PGID sur les identifiants de votre utilisateur DSM. Le premier utilisateur est généralement 1026 et le groupe users 100 ; id en SSH le confirme.
  5. Terminez l’assistant, puis ouvrez l’onglet Journal du conteneur pour le code de jumelage et jumelez Cedar.

Unraid

  1. Enregistrez cedar-server.xml dans /boot/config/plugins/dockerMan/templates-user/ sur la clé flash.
  2. Dans l’onglet Docker, choisissez Ajouter un conteneur et sélectionnez cedar-server dans la liste des modèles.
  3. Vérifiez les chemins Config et Recordings, puis choisissez Appliquer. Le modèle s’exécute sous nobody:users (99:100), comme la plupart des conteneurs Unraid.
  4. Ouvrez le journal du conteneur pour le code de jumelage et jumelez Cedar.

Jumelez Cedar

  1. Trouvez dans le journal le code de jumelage à six chiffres. Un nouveau code apparaît à chaque démarrage, puis toutes les 10 minutes jusqu’à ce qu’un appareil soit jumelé.
  2. Dans Cedar, ouvrez Réglages › TV en direct et DVR › DVR domestique.
  3. Saisissez l’adresse du serveur (par exemple 192.168.1.20), le port 8984 et le code, puis choisissez Jumeler avec le DVR domestique.

Cedar envoie ensuite au serveur les sources de TV en direct et les guides de votre foyer. Choisissez celles qu’il enregistre sous Sources enregistrables. Pour jumeler un autre appareil plus tard, redémarrez le conteneur et utilisez le nouveau code.

Ouvrez http://<adresse>:8984/ dans un navigateur pour afficher une page d’état avec la version, le stockage, les sources et les appareils jumelés. Elle n’affiche jamais le code de jumelage.

Hors de chez vous

Cedar utilise le serveur sur votre réseau domestique. Pour regarder et programmer depuis l’extérieur, donnez au serveur une adresse https:// et définissez-la comme CEDAR_REMOTE_URL :

  • Tailscale : exécutez tailscale serve --bg 8984 sur le serveur et utilisez le nom https://…ts.net qu’il affiche. Les appareils qui exécutent Cedar ont aussi besoin de Tailscale.
  • Proxy inverse : Caddy, Nginx Proxy Manager ou le proxy inverse de Synology, avec un certificat TLS devant le port 8984.

Cedar ne se connecte à une adresse distante qu’en HTTPS. Ne redirigez pas le port 8984 sur votre routeur.

Mises à jour et sauvegardes

Mettez à jour avec docker compose pull puis docker compose up -d, ou Rechercher des mises à jour sur Unraid. L’étiquette 1 suit toutes les versions 1.x ; épinglez une version comme 1.0.0 pour ne mettre à jour qu’à votre convenance.

Sauvegardez le dossier config. Il contient l’identité du serveur, les appareils jumelés, les programmations, les règles et le guide. Les enregistrements sont des fichiers vidéo dans le dossier des enregistrements ; copiez-les où vous voulez.

Confidentialité

Cedar Server s’exécute sur votre ordinateur et ne communique qu’avec vos appareils jumelés et vos propres fournisseurs. Cedar ne reçoit ni vos enregistrements, ni vos sources, ni ce que vous regardez.

Les adresses de fournisseurs et les identifiants de connexion envoyés par Cedar sont conservés dans le dossier config, lisibles uniquement par l’utilisateur du serveur, et ne sont jamais écrits dans le journal. Toute personne qui peut lire ce dossier peut les lire, gardez-le donc privé. La page d’état n’affiche que des nombres, jamais de noms de sources, d’adresses ni de codes.

Pas encore disponible

  • La détection automatique du serveur et le jumelage sans code via votre compte Apple.
  • Cedar pour Mac et Android TV comme clients de Cedar Server.
