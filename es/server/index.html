CEDAR SERVER

Graba la TV en directo sin un Mac.

Cedar Server es el DVR doméstico de Cedar como contenedor Docker gratuito. Ejecútalo en un NAS, un miniordenador, una Raspberry Pi o un VPS, empareja con él Cedar en iPhone, iPad o Apple TV y programa grabaciones que siguen haciéndose con todas las apps cerradas.

Cómo funciona

  1. Ejecuta el contenedor

    Inicia Cedar Server con Docker en un ordenador que se mantenga encendido, como un NAS o un miniordenador.

  2. Empareja Cedar

    En Ajustes › TV en directo y DVR › DVR doméstico, introduce la dirección del servidor y el código de su registro.

  3. Graba

    Cedar envía tus fuentes y guías de TV en directo. Las grabaciones y las reglas de series, títulos y canales siguen funcionando con todas las apps de Cedar cerradas.

Qué necesitas

  • Un ordenador Linux que ejecute Docker, con procesador Intel, AMD o ARM (64 bits). Funcionan Synology, Unraid, TrueNAS, una Raspberry Pi 4 o 5 y la mayoría de miniordenadores.
  • Cedar en iPhone, iPad o Apple TV, compilación 80 o posterior. La app para Mac puede alojar su propio DVR doméstico, pero todavía no puede usar Cedar Server.
  • Una fuente M3U, Xtream o Stalker en Cedar que tengas autorización para usar. Su guía de TV permite que las reglas de series, títulos y canales graben por sí solas.
  • Espacio para las grabaciones: una hora en HD ocupa aproximadamente entre 3 y 6 GB.

Lo mejor es un ordenador en casa. Muchos proveedores bloquean las direcciones de centros de datos o limitan desde cuántos lugares se puede emitir a la vez, así que es posible que un VPS no grabe.

Instalar con Docker Compose

¿Usas un servidor Synology o Unraid? Sigue en su lugar los pasos de Synology o Unraid y después empareja Cedar.

Crea una carpeta para Cedar Server con las carpetas config y recordings dentro, y guarda esto como docker-compose.yml junto a ellas:

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

Establece TZ con tu zona horaria, y PUID y PGID con el usuario y el grupo propietarios de la carpeta de grabaciones (id muestra los tuyos). Después inícialo y observa el registro:

docker compose up -d
docker compose logs -f

A continuación, empareja Cedar con el código del registro.

Synology

  1. Instala Container Manager desde el Centro de paquetes.
  2. En File Station, crea docker/cedar-server con las carpetas config y recordings dentro.
  3. En Container Manager, abre Proyecto › Crear, elige esa carpeta, selecciona Crear docker-compose.yml y pega el archivo de arriba.
  4. Establece PUID y PGID con los ID de tu usuario de DSM. El primer usuario suele ser 1026 y el grupo users, 100; id por SSH lo confirma.
  5. Termina el asistente y abre la pestaña Registro del contenedor para ver el código de emparejamiento y empareja Cedar.

Unraid

  1. Guarda cedar-server.xml en /boot/config/plugins/dockerMan/templates-user/ de la unidad flash.
  2. En la pestaña Docker, elige Añadir contenedor y selecciona cedar-server en la lista de plantillas.
  3. Comprueba las rutas de Config y Recordings y elige Aplicar. La plantilla se ejecuta como nobody:users (99:100), igual que la mayoría de contenedores de Unraid.
  4. Abre el registro del contenedor para ver el código de emparejamiento y empareja Cedar.

Empareja Cedar

  1. Busca en el registro el código de emparejamiento de seis dígitos. Aparece uno nuevo en cada inicio y cada 10 minutos hasta que se empareja un dispositivo.
  2. En Cedar, abre Ajustes › TV en directo y DVR › DVR doméstico.
  3. Introduce la dirección del servidor (por ejemplo 192.168.1.20), el puerto 8984 y el código, y después elige Enlazar con el DVR doméstico.

Cedar envía entonces al servidor las fuentes y guías de TV en directo de tu hogar. Elige cuáles graba en Fuentes grabables. Para emparejar otro dispositivo más adelante, reinicia el contenedor y usa el código nuevo.

Abre http://<dirección>:8984/ en un navegador para ver una página de estado con la versión, el almacenamiento, las fuentes y los dispositivos emparejados. Nunca muestra el código de emparejamiento.

Fuera de casa

Cedar usa el servidor a través de tu red doméstica. Para ver y programar desde otro lugar, dale al servidor una dirección https:// y defínela como CEDAR_REMOTE_URL:

  • Tailscale: ejecuta tailscale serve --bg 8984 en el servidor y usa el nombre https://…ts.net que imprime. Los dispositivos que ejecuten Cedar también necesitan Tailscale.
  • Proxy inverso: Caddy, Nginx Proxy Manager o el proxy inverso de Synology, con un certificado TLS delante del puerto 8984.

Cedar solo se conecta a una dirección remota mediante HTTPS. No redirijas el puerto 8984 en tu router.

Actualizaciones y copias de seguridad

Actualiza con docker compose pull y después docker compose up -d, o con Buscar actualizaciones en Unraid. La etiqueta 1 sigue todas las versiones 1.x; fija una versión como 1.0.0 para actualizar solo cuando tú decidas.

Haz una copia de seguridad de la carpeta config. Contiene la identidad del servidor, los dispositivos emparejados, las programaciones, las reglas y la guía. Las grabaciones son archivos de vídeo en la carpeta de grabaciones; cópialas donde quieras.

Privacidad

Cedar Server se ejecuta en tu ordenador y solo habla con tus dispositivos emparejados y tus propios proveedores. Cedar no recibe tus grabaciones, tus fuentes ni lo que ves.

Las direcciones de proveedor y los inicios de sesión que envía Cedar se guardan en la carpeta config, legibles solo por el usuario del servidor, y nunca se escriben en el registro. Cualquiera que pueda leer esa carpeta puede leerlos, así que mantenla privada. La página de estado muestra solo recuentos, nunca nombres de fuentes, direcciones ni códigos.

Todavía no disponible

  • Fuentes de TV en directo de Jellyfin y Emby. Grábalas con un DVR doméstico en un Mac.
  • Encontrar el servidor automáticamente y emparejar sin código mediante tu cuenta de Apple.
  • Cedar para Mac y Android TV como clientes de Cedar Server.
