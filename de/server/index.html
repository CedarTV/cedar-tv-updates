CEDAR SERVER

Live-TV ohne Mac aufnehmen.

Cedar Server ist der Cedar Heim-DVR als kostenloser Docker-Container. Betreibe ihn auf einem NAS, einem Mini-PC, einem Raspberry Pi oder einem VPS, koppele Cedar auf iPhone, iPad oder Apple TV damit und plane Aufnahmen, die auch bei geschlossenen Apps weiterlaufen.

So funktioniert es

  1. Den Container starten

    Starte Cedar Server mit Docker auf einem Computer, der durchgehend läuft, etwa einem NAS oder Mini-PC.

  2. Cedar koppeln

    Gib unter Einstellungen › Live-TV & DVR › Heim-DVR die Adresse des Servers und den Code aus seinem Protokoll ein.

  3. Aufnehmen

    Cedar sendet deine Live-TV-Quellen und Programmführer. Aufnahmen, Serien-, Titel- und Senderregeln laufen weiter, auch wenn alle Cedar-Apps geschlossen sind.

Was du brauchst

  • Ein Linux-Computer, auf dem Docker läuft, mit Intel-, AMD- oder ARM-Prozessor (64-Bit). Synology, Unraid, TrueNAS, ein Raspberry Pi 4 oder 5 und die meisten Mini-PCs funktionieren.
  • Cedar auf iPhone, iPad oder Apple TV, Build 80 oder neuer. Die Mac-App kann einen eigenen Heim-DVR hosten, aber Cedar Server noch nicht nutzen.
  • Eine M3U-, Xtream- oder Stalker-Quelle in Cedar, die du nutzen darfst. Ihr Programmführer lässt Serien-, Titel- und Senderregeln von selbst aufnehmen.
  • Speicherplatz für Aufnahmen: Eine Stunde HD braucht etwa 3–6 GB.

Ein Computer zu Hause funktioniert am besten. Viele Anbieter sperren Rechenzentrumsadressen oder begrenzen, an wie vielen Orten gleichzeitig gestreamt werden darf, sodass ein VPS womöglich nicht aufnimmt.

Mit Docker Compose installieren

Du nutzt einen Synology- oder Unraid-Server? Folge stattdessen den Schritten für Synology oder Unraid und koppele dann Cedar.

Lege einen Ordner für Cedar Server an, mit den Ordnern config und recordings darin, und speichere dies daneben als docker-compose.yml:

services:
  cedar-server:
    image: ghcr.io/cedartv/cedar-server:1
    container_name: cedar-server
    restart: unless-stopped
    ports:
      - "8984:8984"
    environment:
      TZ: America/New_York
      PUID: "1000"
      PGID: "1000"
    volumes:
      - ./config:/config
      - ./recordings:/recordings

Setze TZ auf deine Zeitzone sowie PUID und PGID auf Benutzer und Gruppe, denen der Aufnahmeordner gehört (id zeigt deine). Starte den Server dann und beobachte das Protokoll:

docker compose up -d
docker compose logs -f

Als Nächstes koppelst du Cedar mit dem Code aus dem Protokoll.

Synology

  1. Installiere den Container Manager aus dem Paket-Zentrum.
  2. Lege in der File Station docker/cedar-server an, mit den Ordnern config und recordings darin.
  3. Öffne im Container Manager Projekt › Erstellen, wähle diesen Ordner, wähle „docker-compose.yml erstellen“ und füge die Datei von oben ein.
  4. Setze PUID und PGID auf die IDs deines DSM-Benutzers. Der erste Benutzer ist meist 1026 und die Gruppe „users“ 100; id per SSH bestätigt es.
  5. Schließe den Assistenten ab, öffne dann den Tab „Protokoll“ des Containers für den Kopplungscode und koppele Cedar.

Unraid

  1. Speichere cedar-server.xml unter /boot/config/plugins/dockerMan/templates-user/ auf dem Flash-Laufwerk.
  2. Wähle auf dem Tab „Docker“ „Container hinzufügen“ und wähle cedar-server aus der Vorlagenliste.
  3. Prüfe die Pfade für Config und Recordings und wähle „Übernehmen“. Die Vorlage läuft als nobody:users (99:100), wie die meisten Unraid-Container.
  4. Öffne das Protokoll des Containers für den Kopplungscode und koppele Cedar.

Cedar koppeln

  1. Den sechsstelligen Kopplungscode findest du im Protokoll. Bei jedem Start erscheint ein neuer, und danach alle 10 Minuten, bis ein Gerät gekoppelt ist.
  2. Öffne in Cedar Einstellungen › Live-TV & DVR › Heim-DVR.
  3. Gib die Adresse des Servers (etwa 192.168.1.20), Port 8984 und den Code ein und wähle dann „Mit Heim-DVR koppeln“.

Cedar sendet dann die Live-TV-Quellen und Programmführer deines Haushalts an den Server. Unter „Aufnahmequellen“ wählst du, welche er aufnimmt. Um später ein weiteres Gerät zu koppeln, starte den Container neu und nutze den neuen Code.

Öffne http://<Adresse>:8984/ in einem Browser, um eine Statusseite mit Version, Speicher, Quellen und gekoppelten Geräten zu sehen. Den Kopplungscode zeigt sie nie.

Unterwegs

Cedar nutzt den Server über dein Heimnetzwerk. Um von anderswo zu schauen und zu planen, gib dem Server eine https://-Adresse und setze sie als CEDAR_REMOTE_URL:

  • Tailscale: Führe tailscale serve --bg 8984 auf dem Server aus und nutze den ausgegebenen Namen https://…ts.net. Auch Geräte mit Cedar brauchen Tailscale.
  • Reverse-Proxy: Caddy, Nginx Proxy Manager oder der Reverse-Proxy von Synology mit einem TLS-Zertifikat vor Port 8984.

Cedar verbindet sich mit einer entfernten Adresse nur über HTTPS. Leite Port 8984 nicht auf deinem Router weiter.

Updates und Backups

Aktualisiere mit docker compose pull und dann docker compose up -d oder, auf Unraid, mit „Nach Updates suchen“. Der Tag 1 folgt jeder 1.x-Version; hefte eine Version wie 1.0.0 an, um nur nach deiner Wahl zu aktualisieren.

Sichere den Ordner config. Er enthält die Identität des Servers, gekoppelte Geräte, Zeitpläne, Regeln und den Programmführer. Aufnahmen sind Videodateien im Aufnahmeordner; kopiere sie, wohin du möchtest.

Datenschutz

Cedar Server läuft auf deinem Computer und spricht nur mit deinen gekoppelten Geräten und deinen eigenen Anbietern. Cedar erhält weder deine Aufnahmen noch deine Quellen oder dein Sehverhalten.

Die Adressen und Anmeldedaten der Anbieter, die Cedar sendet, werden im Ordner config gespeichert, nur für den Benutzer des Servers lesbar, und nie ins Protokoll geschrieben. Wer diesen Ordner lesen kann, kann sie lesen, also halte ihn privat. Die Statusseite zeigt nur Anzahlen, nie Quellennamen, Adressen oder Codes.

Noch nicht verfügbar

  • Live-TV-Quellen von Jellyfin und Emby. Nimm diese mit einem Heim-DVR auf einem Mac auf.
  • Den Server automatisch finden und ohne Code über deinen Apple Account koppeln.
  • Cedar für Mac und Android TV als Clients von Cedar Server.
